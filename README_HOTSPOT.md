# Wi-Fi 热点认证系统 - 自动拦截/放行版

## 功能特性

本系统利用电脑开启的 Wi-Fi 热点，实现对接入设备的 MAC 地址认证和自动防火墙控制。

### 核心功能
- ✅ **JSON 数据存储**：使用 `users.json` 存储用户信息，无需数据库
- ✅ **自动设备发现**：通过 ARP 表扫描连接到热点的设备，获取 MAC 地址
- ✅ **自动拦截未授权设备**：待审核/已拒绝设备只能访问认证页面，无法访问外网
- ✅ **自动放行已批准设备**：审批通过后自动移除防火墙阻止规则
- ✅ **后台监控线程**：每 5 秒同步一次防火墙规则与数据库状态
- ✅ **Web 管理界面**：管理员可在线审批用户申请

## 系统架构

```
[手机/平板等设备] --> [电脑 Wi-Fi 热点] --> [互联网]
                          |
                    [Flask 服务器]
                          |
                    [防火墙规则]
                          |
                    [JSON 数据库]
```

## 工作原理

1. **设备连接热点**：用户设备连接到电脑开启的 Wi-Fi 热点
2. **自动发现**：系统通过 ARP 表获取设备 IP 和 MAC 地址
3. **初始拦截**：新设备默认被防火墙阻止访问外网，只能访问本机 8080 端口
4. **用户注册**：用户打开浏览器访问任意网页，被重定向到认证页面
5. **提交申请**：用户输入账号密码，系统自动创建待审核记录
6. **管理员审批**：
   - **通过**：自动移除防火墙阻止规则，设备可正常上网
   - **拒绝**：保持/添加防火墙阻止规则，设备继续被拦截
7. **实时监控**：后台线程持续同步数据库状态和防火墙规则

## 安装步骤

### 1. 环境要求
- Windows 10/11（支持内置 Wi-Fi 热点功能）
- Python 3.7+
- 管理员权限（用于修改防火墙规则）

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 开启电脑热点
**Windows 设置方法：**
1. 设置 > 网络和 Internet > 移动热点
2. 开启"与其他设备共享我的 Internet 连接"
3. 记下热点网络名称和密码
4. 确保热点网段为 `192.168.137.x`（默认）

### 4. 以管理员身份运行
```bash
# 右键点击命令提示符/PowerShell，选择"以管理员身份运行"
python app_json.py
```

## 使用说明

### 普通用户
1. 连接电脑开启的 Wi-Fi 热点
2. 打开浏览器访问任意网页（如 `http://baidu.com`）
3. 自动跳转到认证页面 `http://192.168.137.1:8080`
4. 输入账号密码登录（首次登录自动创建申请）
5. 等待管理员审批
6. 审批通过后刷新页面即可上网

### 管理员
1. 访问管理后台：`http://localhost:8080/admin`
2. 登录账号：`superadmin` / 密码：`root`
3. 查看待审核用户列表
4. 点击"通过"或"拒绝"按钮
5. 系统自动更新防火墙规则

## 防火墙规则说明

### Windows 防火墙规则命名格式
- 规则名称：`Block_MAC_XXXXXXXXXXXX`（X 为 MAC 地址去掉冒号）
- 规则类型：出站规则（outbound）
- 动作：阻止（block）
- 目标 IP：设备当前 IP 地址

### 查看防火墙规则
```bash
# 查看所有阻止规则
netsh advfirewall firewall show rule name=all | findstr "Block_MAC"
```

### 手动删除规则（可选）
```bash
netsh advfirewall firewall delete rule name="Block_MAC_AABBCCDDEEFF"
```

## 注意事项

⚠️ **重要提示：**

1. **必须以管理员身份运行**：修改 Windows 防火墙规则需要管理员权限
2. **热点网段配置**：默认使用 `192.168.137.x`，如不同请修改 `HOTSPOT_SUBNET` 变量
3. **MAC 地址随机化**：部分手机系统（iOS、Android 10+）默认使用随机 MAC，需在 Wi-Fi 设置中关闭"私有 Wi-Fi 地址"功能
4. **重启后规则保留**：Windows 防火墙规则在系统重启后仍然有效
5. **IP 变化处理**：如果设备 IP 变化，系统会在下次扫描时自动更新规则
6. **仅适用于热点场景**：此方案要求所有设备流量经过电脑热点，不适用于普通路由器环境

## 故障排查

### 问题：无法获取设备 MAC 地址
**解决：**
- 确保设备已连接到热点
- 检查 ARP 表：`arp -a`
- 确认热点网段配置正确

### 问题：防火墙规则不生效
**解决：**
- 确认以管理员身份运行
- 检查 Windows 防火墙服务是否开启
- 查看程序输出日志中的错误信息

### 问题：设备无法访问认证页面
**解决：**
- 确保防火墙规则允许访问本机 8080 端口
- 检查 Flask 服务器是否正常启动
- 尝试直接访问 `http://192.168.137.1:8080`

## 安全建议

1. **修改默认密码**：首次使用后修改 `superadmin` 密码
2. **更改密钥**：修改 `app.secret_key` 为随机字符串
3. **局域网部署**：仅在可信网络环境中使用
4. **定期备份**：定期备份 `users.json` 文件
